# Задача: встроить видео в секцию «Ценность актива»

## Контекст

В проекте уже реализована отдельная секция с вертикальным видео между блоками «Ценность актива» и «Концепция». Отдельный блок не подходит для desktop из-за вертикального формата ролика и пустого пространства по бокам.

Перед началом изучить:

- `AGENTS.md`
- `AI_CONTEXT.md`
- `DEPLOYMENT.md`
- `TODO.md`
- текущую реализацию видеосекции
- компонент секции «Ценность актива»

## Цель

Убрать отдельную видеосекцию и встроить видео внутрь существующего блока «Ценность актива».

## Требования

### Структура страницы

Удалить отдельную секцию видео из порядка блоков.

Порядок страницы:

```text
Ценность актива
Концепция
```

Видео должно находиться внутри компонента «Ценность актива».

Удалить:

- заголовок «Проект в деталях»;
- пустую секцию;
- лишние вертикальные отступы.

### Desktop

Сделать двухколоночную композицию:

```text
| текст и характеристики | вертикальное видео |
```

Требования:

- текст слева;
- видео справа;
- сохранить заголовок «Ценность актива»;
- не добавлять отдельный заголовок видео;
- сохранить текущую типографику и стили блока;
- ориентир ширины колонок — 60/40 или 65/35;
- ширина видео ориентировочно 280–380 px;
- высоту согласовать с текстовой частью;
- сохранить исходное соотношение сторон;
- не растягивать ролик;
- использовать существующие радиусы, рамки, тени и отступы;
- весь блок должен оставаться внутри общего контейнера сайта.

### Mobile

Порядок элементов:

```text
заголовок «Ценность актива»
текст и характеристики
видео
```

Требования:

- видео под всем текстовым содержимым;
- ширина адаптируется к контейнеру;
- нет горизонтального скролла;
- разумный отступ между текстом и видео;
- сохранить `playsInline`;
- кнопка звука остаётся доступной, если она уже реализована.

### Breakpoints

- mobile/tablet: одна колонка;
- desktop: две колонки примерно с `lg`.

Не использовать две узкие колонки на планшетах, если это ухудшает читаемость.

### Видео

Сохранить уже реализованные возможности:

- MP4/WebM;
- poster;
- lazy loading;
- autoplay только без звука;
- `muted`;
- `playsInline`;
- `loop`;
- `prefers-reduced-motion`;
- остановку вне viewport, если реализована;
- кнопку включения звука, если реализована.

Не использовать GIF. Не добавлять тяжёлый исходник в Git или production.

### Код

Предпочтительно:

- удалить отдельный компонент видеосекции, если он больше не нужен;
- оставить или выделить небольшой компонент видеоплеера;
- встроить его в секцию «Ценность актива»;
- не дублировать логику воспроизведения;
- не добавлять зависимости;
- не менять остальные секции.

## Проверка адаптивности

Проверить:

- 320 px;
- 375 px;
- 390 px;
- 768 px;
- 1024 px;
- 1280 px;
- 1440 px.

Проверить:

- читаемость текста;
- баланс колонок;
- отсутствие переполнения и горизонтального скролла;
- корректную высоту видео;
- отсутствие лишнего заголовка;
- плавный переход к блоку «Концепция».

## Технические проверки

Выполнить:

```bash
npm run build
npm run preview
docker build -t sk-develop .
```

Убедиться:

- отдельная видеосекция удалена;
- видео находится внутри «Ценности актива»;
- desktop: текст слева, видео справа;
- mobile: видео под текстом;
- нет ошибок Console;
- нет 404 для медиа;
- поведение видео не сломано;
- «Концепция» идёт сразу после «Ценности актива».

## Документация и Git

Обновить:

- `TODO.md`;
- при необходимости `AI_CONTEXT.md`.

Создать Git-коммит:

```text
refactor: integrate project video into asset value section
```

Push и production-деплой не выполнять.
