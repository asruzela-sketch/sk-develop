# ТЗ: Обновление сайта (локально)

## Цель

Внести изменения только локально. Сервер не изменять, деплой не
выполнять.

## Перед началом

Изучить: - AGENTS.md - AI_CONTEXT.md - DEPLOYMENT.md - TODO.md

## Правки

### 1. Обновить площади

-   Гостиница: 28 186,3 м²
-   ТЦ и офисы: 7 788,2 м²
-   Площадь МФК: 40 215,1 м²
-   Площадь участка: 6 038 м²

### 2. Раздел «Текущая стадия»

Удалить: «Получение ГПЗУ апр 2026»

Добавить: «Внесены изменения в функциональное назначение участка,
утверждена функциональная зона О1».

### 3. Добавить изображение

Использовать приложенную карту участка.

Требования: - встроить в существующую секцию; - сохранить стиль сайта; -
не копировать дизайн примера; - использовать существующие карточки,
отступы и типографику; - обеспечить адаптивность.

## Проверка

Выполнить:

``` bash
npm run build
docker build -t sk-develop .
docker run --rm -p 8080:80 sk-develop
```

Проверить: - новые площади; - новый текст; - отображение изображения; -
мобильную версию; - отсутствие ошибок в консоли.

## Ограничения

-   не выполнять деплой;
-   не изменять сервер;
-   не менять бизнес-логику.

## Отчёт

Предоставить: - список изменённых файлов; - описание реализации; -
результаты сборки и Docker; - что проверить визуально перед публикацией.
