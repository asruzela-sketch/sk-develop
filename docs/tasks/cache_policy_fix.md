# Cache policy после деплоя

## Цель

Устранить ситуацию, когда часть пользователей после деплоя продолжает
видеть старую версию сайта из-за кэширования.

## Перед началом

Изучить: - AGENTS.md - AI_CONTEXT.md - DEPLOYMENT.md - TODO.md

## Задачи

1.  Проверить HTTP-заголовки главной страницы, index.html и assets.
2.  Проверить host-level Nginx reverse proxy.
3.  Настроить:

-   index.html: no-cache, no-store, must-revalidate;
-   JS/CSS с hash --- длительное кэширование;
-   изображения/видео без immutable, если они обновляются под тем же
    именем.

4.  Выполнить:

``` bash
sudo nginx -t
sudo systemctl reload nginx
```

5.  Проверить:

``` bash
curl -I https://снк-девелоперскийпроект.рф
curl -I https://снк-девелоперскийпроект.рф/index.html
```

6.  Проверить HTTPS.
7.  При необходимости обновить DEPLOYMENT.md и TODO.md.

## Ограничения

Не менять Docker и код приложения без необходимости.

## Отчёт

Указать: - какие заголовки были и стали; - какой Nginx-файл изменён; -
нужны ли пользователям дополнительные действия; - обновлена ли
документация.
