# ТЗ: Дополнительные правки сайта (локально)

## Цель

Внести дополнительные изменения в сайт **только локально**, без деплоя на сервер.

## Перед началом

Изучить файлы проекта:

- `AGENTS.md`
- `AI_CONTEXT.md`
- `DEPLOYMENT.md`
- `TODO.md`

Также учитывать результат предыдущего локального этапа, где уже были внесены правки по площадям, тексту в разделе «Текущая стадия» и добавлению изображения карты участка.

---

## Задачи

### 1. Поменять местами фото

Нужно поменять местами изображения в разделе, где после предыдущей правки отображаются два визуальных блока/фото.

Требования:

- поменять порядок изображений на десктопе;
- поменять порядок изображений на мобильной версии;
- сохранить текущую сетку, отступы, скругления и общий стиль сайта;
- не ломать адаптив;
- не менять тексты, если задача этого не требует.

Ожидаемый результат:

- то изображение, которое сейчас стоит первым, должно стать вторым;
- то изображение, которое сейчас стоит вторым, должно стать первым;
- порядок должен быть одинаково логичным и на десктопе, и на мобильной версии.

---

### 2. Перенести блок с видео

Сейчас блок с видео находится в конце страницы.

Нужно перенести его выше:

- блок с видео должен располагаться **перед разделом «Транспортная доступность»**;
- видео не должно оставаться последним блоком страницы;
- сохранить внешний вид блока;
- не менять само видео;
- не менять стили без необходимости;
- проверить, что порядок секций на странице стал корректным.

Ожидаемый порядок:

```text
...
Раздел с концепцией / текущей стадией
Видео-блок
Транспортная доступность
...
Footer
```

Точный порядок уточнить по текущей структуре компонентов проекта.

---

## Ограничения

- Не выполнять деплой.
- Не подключаться к серверу.
- Не пересобирать Docker на сервере.
- Не менять домен, SSL, Nginx и серверные настройки.
- Не менять бизнес-логику.
- Не менять Docker-конфигурацию.
- Не переписывать дизайн, только переставить нужные блоки.

---

## Проверка

После внесения изменений выполнить локально:

```bash
npm run build
docker build -t sk-develop .
docker run --rm -p 8080:80 sk-develop
```

Проверить в браузере:

- главная страница открывается;
- изображения поменялись местами на десктопе;
- изображения поменялись местами на мобильной версии;
- видео-блок расположен перед разделом «Транспортная доступность»;
- страница не ломается визуально;
- нет критических ошибок в консоли.

---

## Отчёт после выполнения

Предоставить:

- список изменённых файлов;
- что именно поменялось по изображениям;
- куда перенесён видео-блок;
- результат `npm run build`;
- результат Docker-проверки;
- что нужно проверить визуально перед публикацией.
