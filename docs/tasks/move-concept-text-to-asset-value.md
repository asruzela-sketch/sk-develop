# Задача: перенести текст из блока «Концепция» в блок «Ценность актива»

## Контекст

После интеграции вертикального видео в блок «Ценность актива» в левой колонке под карточками осталось большое пустое пространство.

Новые тексты для сайта добавлять запрещено.

Разрешается использовать только существующий контент сайта.

## Цель

Заполнить пустое пространство в блоке «Ценность актива» существующим текстом из блока «Концепция».

## Требования

### 1. Перенос текста

Из блока «Концепция» перенести следующий текст:

> Сбалансированная структура коммерческих и гостиничных функций с учётом локации и градостроительных параметров.

После переноса этот текст должен полностью исчезнуть из блока «Концепция».

### 2. Размещение

Разместить текст:

- под карточками преимуществ;
- в свободной области слева от видео;
- внутри блока «Ценность актива».

Не создавать для него новый заголовок.

### 3. Оформление

Использовать абсолютно те же стили, что уже применяются к тексту над карточками.

Не изменять:

- размер шрифта;
- цвет;
- межстрочный интервал;
- толщину;
- ширину текстового блока.

Текст должен восприниматься как естественное продолжение существующего описания.

### 4. Запрещено

Не добавлять:

- новые формулировки;
- новые преимущества;
- новые заголовки;
- новые CTA;
- новый маркетинговый текст.

Использовать исключительно существующий текст сайта.

### 5. Проверить

Убедиться, что:

- композиция блока стала визуально сбалансированной;
- пустое пространство исчезло;
- блок «Концепция» не выглядит сломанным после удаления текста;
- мобильная версия сохранила корректный порядок элементов;
- остальные секции сайта не изменились.

## Критерии готовности

- [ ] текст перенесён в блок «Ценность актива»;
- [ ] в блоке «Концепция» этого текста больше нет;
- [ ] стиль полностью совпадает с текстом над карточками;
- [ ] новые тексты не добавлены;
- [ ] композиция desktop стала более сбалансированной;
- [ ] мобильная версия не сломана;
- [ ] выполнены проверки и создан Git-коммит.
